Non-training attribute control: gravity, camera, brightness, quality

Mixed result · magnitude sweep complete · quality is a clean dial, gravity has no effect at any scale, camera/brightness have narrow or no usable window · no training, no LoRA anywhere

A pivot from the case-by-case steering vectors on the earlier page, which each extracted a direction as teacher-minus-base on one specific clip -- tangled up with that clip's own content. Here the direction is built from prompt-contrastive pairs across 3 different scenes, on base H3 alone (zero LoRA, zero trained checkpoints, construction included), averaged into one generic direction, then tested on a 4th held-out scene's own neutral prompt. Checked with dense frame sampling and quantitative pixel metrics, not a sparse eyeball check, per the correction on the earlier page.

Method: for each of 3 source scenes (duck-falls-in-box, potato-in-water, domino-in-juice), run base H3 twice with the identical seed and reference image, changing only the prompt along one attribute axis. Hook every transformer block in both runs, record each block's real output (mean over packed-sequence rows) at 7 representative denoising steps, diff the two runs, average over all steps and all 3 scenes into one direction per block. Add that direction to blocks L30–L49 (the span established in the earlier page's causal test) on a fresh base H3, generating a held-out 4th scene (paper-fall-water) from its own neutral prompt -- no attribute language added.
Result: this doesn't work at raw magnitude. Unlike the earlier page's per-case vectors -- built from a teacher/base replay on the literal same input, which isolates one block's weight-difference effect and stays small -- these vectors are built from two independently sampled generations that diverge in content within a few steps. The diff this produces is a much larger, noisier signal (whole-trajectory divergence, not one block's isolated effect), and adding it unscaled, every step, to 20 blocks compounds it further. Final reading: magnitude, not direction, really was the problem for avoiding outright collapse -- confirmed. But that doesn't mean every direction becomes a useful dial once scaled down. Gravity never shows any visible effect at any tested scale (0.05-0.5) -- the held-out scene's failure (paper frozen at the tongs) is identical at every scale, only image sharpness degrades as scale rises; this direction doesn't appear to encode anything the held-out generation responds to. Camera has a narrow coherent band (≤0.1) with no visible pan, then collapses directly into noise by 0.2 -- no scale produces real camera motion. Brightness has a real but very narrow usable window (≈0.02), saturating by 0.05. Quality is the one clean success: a smooth, monotonic, controllable sharpness increase from 0.02 to 0.2x with zero visible artifacts -- the only one of the four that behaves like an actual dial so far.
